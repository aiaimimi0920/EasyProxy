# EasyProxy 云套件 SBA 运维入口

本目录包含云套件的生命周期、部署、审计、受保护更新和恢复实现。
文档描述执行合同，不把源码存在、本地测试通过或历史成功回执当作当前线上健康证明。
旧阶段计划、任务编号、一次性恢复批准和测试流水账保留在 Git 历史，不作为新操作授权。

## 不变的操作边界

- 固定批准源码与 gitlink，构建与状态放在源码外，不使用未提交工作树冒充发布版本。
- 秘密只从声明的受保护入口取得，不写入公开配置、日志或回执。
- update、refresh 与受限恢复必须遵守共同 writer；UNKNOWN 不自动重试、回滚或清锁。
- 恢复入口与准确父任务、版本和证据绑定，历史批准不能复用于当前操作。
- 独立 verify、业务代理消费与部署回执是不同证据，按真实结果分别记录。
- 本文不授权云写入、删除、发布或收费；保留实际数据备份和原始失败证据。
